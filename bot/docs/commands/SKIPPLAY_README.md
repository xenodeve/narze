# SkipPlay Command

คำสั่ง `skipplay` ใช้สำหรับลัดคิวเล่นเพลงทันที โดยจะหยุดเพลงปัจจุบันและเล่นเพลงใหม่ที่เลือกไว้หน้าสุด

## ฟีเจอร์

✅ ลัดคิวเล่นเพลงใหม่ทันที  
✅ รักษาคิวเก่าไว้ (เพิ่มหลังเพลงใหม่)  
✅ รองรับทั้งเพลงเดียวและ playlist  
✅ Autocomplete support  
✅ ตรวจสอบเงื่อนไขครบถ้วน  

## การใช้งาน

### เงื่อนไขที่ต้องการ
1. ต้องมีเพลงเล่นอยู่ก่อนหน้า
2. ผู้ใช้ต้องอยู่ในห้องเสียง
3. ผู้ใช้ต้องอยู่ในห้องเดียวกับบอท (หากบอทเข้าห้องแล้ว)

### วิธีใช้
```
/skipplay query: ชื่อเพลง หรือ URL
```

### ตัวอย่าง
```
/skipplay query: see you again
/skipplay query: https://www.youtube.com/watch?v=RgKAFK5djSk
/skipplay query: https://music.youtube.com/playlist?list=PLqUySH4LapbDFxDzLQZ7OLiBKPnJCaO3b
```

## การทำงาน

### สำหรับเพลงเดียว
1. สำรองคิวปัจจุบัน
2. ล้างคิว  
3. เพิ่มเพลงใหม่
4. เพิ่มคิวเก่ากลับ
5. หยุดเพลงปัจจุบัน (เพื่อเริ่มเพลงใหม่)

### สำหรับ Playlist
1. สำรองคิวปัจจุบัน
2. ล้างคิว
3. เพิ่มทั้ง playlist
4. เพิ่มคิวเก่ากลับ
5. หยุดเพลงปัจจุบัน (เพื่อเริ่ม playlist ใหม่)

## Error Handling

### Autocomplete Errors
- `ไม่มีเพลงก่อนหน้า ไม่สามารถใช้ skipplay ได้` - ไม่มี player หรือไม่มีเพลงเล่น
- `กรุณาระบุเพลง` - ไม่ได้ใส่ query
- `ไม่รองรับ Platform นี้` - ใส่ URL จาก Deezer หรือ Apple Music
- `(ข้อผิดพลาด) กรุณาใส่ URL ที่ถูกต้อง` - URL ไม่ถูกต้อง
- `ไม่พบเพลงที่ค้นหา` - ไม่เจอผลลัพธ์

### Execute Errors
- `กรุณาระบุเพลง` - query ว่างหรือ 'no_song'
- `กรุณาระบุเพลงที่ถูกต้อง` - query เป็น 'error'
- `กรุณาเข้าห้องเสียงด้วย` - ผู้ใช้ไม่ได้อยู่ในห้องเสียง
- `คุณต้องอยู่ในห้องเดียวกับบอท` - ผู้ใช้อยู่คนละห้องกับบอท
- `ไม่รองรับ Platform นี้` - URL จาก platform ที่ไม่รองรับ
- `ไม่มีเพลงก่อนหน้า` - ไม่มี player หรือไม่มีเพลงเล่น
- `ไม่สามารถเข้าถึงเพลงได้` - ไม่พบเพลงที่ต้องการ
- `เกิดข้อผิดพลาดในการ skipplay` - error อื่นๆ

## Response Messages

### เพลงเดียว
```
⏭️┃ ชื่อเพลง [ระยะเวลา]
```

### Playlist
```
⏭️ Skip Play Playlist: ชื่อ playlist
⌛ เวลา: [ระยะเวลารวม]
📊 มี: [จำนวนเพลง] เพลง
```

## Technical Details

### Queue Management
- ใช้ `player.queue.clear()` เพื่อล้างคิว
- ใช้ `player.queue.add()` เพื่อเพิ่มเพลง
- ใช้ `player.stop()` เพื่อหยุดเพลงปัจจุบันและไปเพลงถัดไป
- สำรองคิวเดิมด้วย spread operator `[...player.queue]`

### Response Handling  
- ใช้ `interaction.deferReply()` สำหรับการประมวลผลที่ใช้เวลานาน
- ใช้ `interaction.editReply()` เพื่อส่งผลลัพธ์

### Autocomplete
- ตรวจสอบสถานะ player ก่อนแสดงตัวเลือก
- ส่งคืน URI สำหรับ search results เพื่อความแม่นยำ
- จำกัดผลลัพธ์ไว้ที่ 7 รายการ
